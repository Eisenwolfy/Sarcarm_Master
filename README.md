# Sarcarm Master

**Context-aware sarcasm detection for Reddit comments using deep learning and Transformer-based models.**

Sarcarm Master is an NLP project focused on detecting sarcasm in Reddit comments. The project explores how different architectures perform as the model evolves from recurrent networks trained from scratch to pretrained Transformer-based models, with particular attention to parent-comment context and local feature extraction.

The project uses the **Sarcastic Comments on Reddit** dataset containing approximately **1.01 million labeled comments**.

---

## Overview

Sarcasm is often difficult to detect from a comment alone.

For example:

> **Parent:** "I really enjoyed spending three hours fixing this bug."

> **Comment:** "Yeah, what a wonderful way to spend a Saturday."

The comment itself may look positive, but the relationship between the comment and its context reveals the sarcastic intent.

The experiments use:

* the target comment;
* its `parent_comment`;
* subreddit information;
* Reddit score;
* contextual representations generated by pretrained Transformers.

---

## Dataset

The project uses the **Sarcastic Comments on Reddit** dataset. (https://www.kaggle.com/datasets/sherinclaudia/sarcastic-comments-on-reddit)

Each example contains:

| Feature          | Description                            |
| ---------------- | -------------------------------------- |
| `comment`        | Target Reddit comment                  |
| `parent_comment` | Comment the target comment replies to  |
| `subreddit`      | Subreddit where the comment was posted |
| `score`          | Reddit score                           |
| `label`          | `0` — not sarcasm, `1` — sarcasm       |

The dataset contains approximately **1.01 million examples** with an almost perfectly balanced class distribution:

* ~505k non-sarcastic comments
* ~505k sarcastic comments

The experiments use an 80/10/10 stratified train/validation/test split.

# Model Evolution

The project was developed incrementally rather than starting with a large pretrained model.

The main goal was to determine which architectural components actually improve sarcasm detection.

## 1. Basic LSTM

**File:** `models/basic_lstm.py`

The first model uses a traditional recurrent architecture trained from scratch.

```text
Text
 ↓
Tokenization
 ↓
Learned Embeddings
 ↓
LSTM
 ↓
Classifier
```

This model served as the initial deep-learning baseline.

The purpose of this model was to establish how far a model trained only on the target dataset could go without pretrained language representations.

---

## 2. LSTM with Parent Comment

**File:** `models/parent_comment_handling.py`

The next version introduced the parent comment as a second input.

```text
                 ┌── Comment → LSTM ──┐
Input            │                    │
                 └── Parent  → LSTM ──┘
                          ↓
                       Fusion
                          ↓
                     Classifier
```

The motivation was that sarcasm is frequently expressed through a contrast between a comment and the statement it responds to.

This version established the **context-aware** direction of the project.

---

## 3. DistilBERT + BiLSTM + Attention

**File:** `models/model_with_distilbert.py`

The next stage replaced the learned word embeddings with contextual representations generated by DistilBERT.

```text
Comment
   ↓
DistilBERT
   ↓
BiLSTM
   ↓
Attention
   ↓
Comment representation

Parent
   ↓
DistilBERT
   ↓
BiLSTM
   ↓
Attention
   ↓
Parent representation
    ↓
  Fusion
    ↓
Classification
```

DistilBERT provides contextual token representations, while the BiLSTM and attention mechanism attempt to model the most informative parts of each sequence.

---

## 4. DistilBERT Pair Classifier

**File:** `models/pure_bert.py`


Instead of separately processing the comment and parent comment, they are provided to DistilBERT as a sentence pair:

```text
[CLS] comment [SEP] parent [SEP]
                    ↓
                DistilBERT
                    ↓
                  [CLS]
                    ↓
                Classifier
```

This allows the Transformer's self-attention mechanism to process the two pieces of text within the same contextual representation.

The experiment demonstrated that a relatively simple pretrained Transformer can already provide strong performance on this task.

**Accuracy: ~78.2%**

---

## 5. DistilBERT + CNN

**File:** `models/bert_cnn.py`

CNN filters capture local patterns across the contextualized token representations.

The model also experimented with Reddit metadata such as subreddit embeddings and score features.

```text
                 DistilBERT
                     ↓
             Token representations
                     ↓
          ┌──────────┼──────────┐
          ↓          ↓          ↓
       Conv-3     Conv-4     Conv-5
          ↓          ↓          ↓
       MaxPool     MaxPool    MaxPool
          └──────────┼──────────┘
                     ↓
                  Fusion
                     ↓
                Classifier
```

**Best observed accuracy: ~78.5%**

---

## 6. DistilBERT + BiLSTM + Attention + CNN + Metadata

**File:** `models/lstm_bert_cnn.py`

The final experimental architecture combined most of the explored components:

```text
                    DistilBERT
                        ↓
              ┌─────────┴─────────┐
              ↓                   ↓
           Comment              Parent
              ↓                   ↓
        ┌─────┴─────┐       ┌─────┴─────┐
        ↓           ↓       ↓           ↓
      BiLSTM       CNN    BiLSTM       CNN
        ↓           ↓       ↓           ↓
     Attention      │    Attention      │
        └─────┬─────┘       └─────┬─────┘
              └─────────┬─────────┘
                        ↓
                     Fusion
                        +
               Reddit metadata
                        ↓
                   Classifier
```

The model combines:

* DistilBERT contextual representations
* bidirectional LSTMs
* attention
* CNN feature extraction
* subreddit embeddings
* Reddit score features

Despite being substantially more complex, the architecture did not outperform the simpler DistilBERT + CNN model.

**Test accuracy: 77.96%**

This experiment demonstrated an important result of the project:

> Increasing architectural complexity does not necessarily improve performance when a pretrained Transformer already provides strong contextual representations.

# Model Comparison

| Model                                            | Main idea                                                 |   Accuracy |
| ------------------------------------------------ | --------------------------------------------------------- | ---------: |
| Basic LSTM                                       | Learned embeddings + LSTM                                 |  **73.3%** |
| LSTM + Parent                                    | Separate comment/parent processing                        |  **76.2%** |
| DistilBERT + BiLSTM + Attention                  | Transformer representations + recurrent sequence modeling |  **77.8%** |
| DistilBERT Pair                                  | Comment + parent encoded as a sentence pair               |  **78.2%** |
| DistilBERT + CNN                                 | Transformer + local feature extraction                    |  **78.5%** |
| DistilBERT + BiLSTM + CNN + Attention + Metadata | Full hybrid architecture                                  | **77.96%** |

# How Accuracy Could Be Improved

The project was intentionally stopped after establishing a strong Transformer-based baseline rather than endlessly increasing model complexity.

Several changes could potentially improve performance:

### 1. Use BERT instead of DistilBERT

The project currently uses:

```text
distilbert-base-uncased
```

A full BERT model provides a larger Transformer representation and could potentially improve classification quality at the cost of substantially higher memory usage and training time.

---

### 2. Fine-tune all Transformer layers

Several experiments freeze the embedding layer and the first Transformer layers.

Allowing the complete Transformer to adapt to Reddit sarcasm could potentially improve domain-specific representations.

---

### 3. Better parent/comment interaction

The current dual-input architectures mostly encode the comment and parent separately and concatenate their representations.

A stronger architecture could explicitly model their relationship using:

* cross-attention;
* element-wise difference;
* element-wise multiplication;
* joint Transformer encoding.

For example:

```text
comment representation
parent representation
        ↓
 ┌──────┼──────┐
 │      │      │
concat  |c-p|  c×p
 └──────┼──────┘
        ↓
    classifier
```

---

### 4. Longer context

Sarcasm can depend on information appearing later in a comment or parent comment.

Increasing the maximum sequence length could allow the model to retain more contextual information.

---

### 5. Better hyperparameter search

The experiments use manually selected values for:

* learning rate;
* dropout;
* CNN filter count;
* sequence length;
* number of frozen Transformer layers;
* classifier dimensions.

A systematic hyperparameter search could potentially improve the final score.

The project also includes a small PyQt5 interface for running inference on a comment.

The interface accepts:

* a Reddit comment;
* an optional parent comment;

and returns:

* predicted class;
* model confidence.

# Conclusion

Sarcarm Master was developed as an iterative investigation into sarcasm detection using increasingly sophisticated NLP architectures.

The main progression was:

```text
LSTM
  ↓
Parent-aware LSTM
  ↓
DistilBERT + BiLSTM + Attention
  ↓
DistilBERT sentence-pair classifier
  ↓
DistilBERT + CNN
  ↓
Full hybrid architecture
```

The experiments showed that **a simpler Transformer-based architecture achieved the strongest observed result**, reaching approximately **78.5% accuracy**.

The project therefore demonstrates an important practical ML lesson:

> More components do not automatically produce a better model. Architectural complexity should be justified by measurable improvements.
